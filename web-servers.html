Web Servers

A web server is a computer system that stores, processes, and delivers web pages to users over the Internet. When you visit a website, it is a web server that receives your request and sends back the files your browser needs to display the page.

What is a Web Server?

A web server is both the hardware (physical machine) and the software (program) that serves web content to users. Every website on the Internet is hosted on a web server somewhere in the world — running 24 hours a day, 7 days a week.

When you type a URL into your browser and press Enter, your browser sends an HTTP request to the web server hosting that website. The server then processes the request and sends back the appropriate HTML, CSS, images, and other files needed to display the page.

Web servers are designed to handle thousands of requests simultaneously from users all around the world at the same time.

How a Web Server Works Step by Step

  1. A user types a URL into their browser and presses Enter
  2. The browser performs a DNS lookup to find the IP address of the web server hosting that domain
  3. The browser sends an HTTP or HTTPS request to that IP address
  4. The web server software receives the request and locates the requested files on its storage system
  5. The server sends back an HTTP response containing the requested HTML file and a status code (e.g., 200 OK for success)
  6. The browser receives the files and renders the web page on the user's screen

Popular Web Server Software

  • Apache HTTP Server: The most widely used web server software in the world. Free, open-source, and runs on Linux, Windows, and Mac. Powers over 30% of all websites.
  • Nginx (pronounced Engine-X): A high-performance web server known for its speed and ability to handle large numbers of simultaneous connections efficiently. Commonly used for high-traffic websites.
  • Microsoft IIS (Internet Information Services): A web server built into Windows Server operating systems. Commonly used in enterprise environments running Microsoft technologies.
  • LiteSpeed: A high-speed commercial web server that is significantly faster than Apache and widely used by web hosting companies.
  • Node.js: While primarily a JavaScript runtime, Node.js is frequently used to build custom web servers for real-time web applications.

Types of Web Servers

Static Web Server: Delivers files exactly as they are stored on the server without any processing. Suitable for simple websites with fixed content that does not change based on user interaction.

Dynamic Web Server: Processes requests using server-side scripts and databases before sending a response. The content can change based on who is logged in, what they searched for, or other conditions. Used by e-commerce sites, social media, and web applications.

Virtual Server: A single physical machine that is divided into multiple virtual servers using software. Each virtual server behaves as an independent server and can host a completely different website.

HTTP Status Codes

When a web server responds to a browser request, it includes a status code that indicates the result of the request:

  • 200 OK — The request was successful and the page was found and delivered
  • 301 Moved Permanently — The page has been permanently moved to a new URL
  • 403 Forbidden — The server understood the request but refuses to authorize it
  • 404 Not Found — The requested page or file does not exist on the server
  • 500 Internal Server Error — The server encountered an unexpected problem and could not complete the request

Web Server vs Web Browser

These two terms are often confused by beginners but they serve completely opposite roles:

A web browser (Chrome, Firefox, Safari) runs on your device and requests web pages. It is the client side of the communication.

A web server runs on a remote computer in a data centre and serves those web pages in response to browser requests. It is the server side of the communication.

Together, they form the client-server model that powers the entire World Wide Web.

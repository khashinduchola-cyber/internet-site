IP Address — Internet Protocol Address

An IP Address is a unique numerical label assigned to every device connected to a computer network. It serves two main purposes — identifying the host device and providing its location so data can be delivered correctly.

What is an IP Address?

IP stands for Internet Protocol. An IP address is like a home address for your device on the Internet or a local network. Just as a postal system needs your home address to deliver a letter, the Internet needs your IP address to deliver data to the right device.

Every smartphone, laptop, server, printer, and smart device connected to a network has its own IP address that makes it uniquely identifiable.

IPv4 — The Original Format

IPv4 (Internet Protocol version 4) is the most widely used format. It consists of four sets of numbers separated by dots, where each number ranges from 0 to 255.

Example: 192.168.1.1

IPv4 supports approximately 4.3 billion unique addresses. However, due to the explosive growth of Internet connected devices, these addresses have nearly all been used up, which led to the creation of IPv6.

IPv6 — The Modern Format

IPv6 (Internet Protocol version 6) was developed to solve the address shortage problem. It uses 128-bit addresses written in hexadecimal, separated by colons.

Example: 2001:0db8:85a3:0000:0000:8a2e:0370:7334

IPv6 supports an astronomically large number of addresses — approximately 340 undecillion (340 trillion trillion trillion), enough for every device on Earth for the foreseeable future.

Types of IP Addresses

  • Public IP Address: Assigned by your Internet Service Provider (ISP). This is the address the outside world sees when you connect to the Internet.
  • Private IP Address: Used within a local network (e.g., your home WiFi). Devices on the same network communicate using private addresses.
  • Static IP Address: A fixed address that never changes. Used by servers and businesses that need a consistent address.
  • Dynamic IP Address: An address that changes each time you connect to the Internet. Assigned automatically by a DHCP server. Most home users have dynamic IPs.

How IP Addresses Work

When you visit a website, your device sends a request from your IP address to the server's IP address. The server receives the request and sends the webpage data back to your IP address. This exchange happens in milliseconds every time you browse the web.

DNS (Domain Name System) plays a key role here — it translates human-friendly domain names like www.google.com into the numerical IP addresses that computers use to communicate.

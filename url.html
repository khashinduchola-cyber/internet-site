URL — Uniform Resource Locator

A URL is the complete web address used to locate a specific resource such as a page, image, or file on the Internet. It is the text you type into a browser's address bar to visit a website.

What is a URL?

URL stands for Uniform Resource Locator. It is a standardized address format that specifies exactly where a resource lives on the Internet and how to retrieve it.

Every webpage, image, video, and file accessible on the web has a unique URL that identifies it precisely among billions of other resources online.

Anatomy of a URL

Consider this example URL:

https://www.example.com/page?id=5#section

  • https:// — Protocol (how to access the resource)
  • www — Subdomain
  • example.com — Domain name (the website address)
  • /page — Path to the specific resource or file
  • ?id=5 — Query string (passes extra information)
  • #section — Fragment (jumps to a specific part of the page)

Types of URLs

Absolute URL: Contains the full address including protocol and domain name. Used when linking to external websites.

Example: https://www.google.com/search

Relative URL: Contains only the path from the current page location. Used when linking to other pages within the same website.

Example: ../images/photo.jpg

Why URLs Matter

Without URLs, navigating the Internet would be impossible. Every time you click a link, search for a website, or share a webpage, you are using a URL. They are the addressing system that makes the World Wide Web work.

URLs also play an important role in Search Engine Optimization (SEO) — clear, descriptive URLs help search engines and users understand what a page is about before visiting it.

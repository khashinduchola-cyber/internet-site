HTML — HyperText Markup Language

HTML is the standard markup language used to create and structure content on the web. It forms the skeleton of every webpage, defining elements such as headings, paragraphs, links, images, and lists using a system of opening and closing tags.

What is HTML?

HyperText Markup Language (HTML) is the foundation of every single page on the World Wide Web. The word HyperText refers to hyperlinks — the links that connect web pages to one another. The word Markup refers to the tags used to label, annotate, and structure content on a page.

HTML is not a programming language — it does not perform logic or calculations. It is a markup language that tells the web browser how to display and organize content on screen.

Basic HTML Document Structure

Every HTML file follows this essential structure that the browser expects to find:

  • <!DOCTYPE html> — Declares to the browser that this is an HTML5 document
  • <html> — The root element that wraps the entire page content
  • <head> — Contains metadata such as the page title, character set, and links to CSS stylesheets
  • <body> — Contains all the visible content that appears on the page in the browser window

Most Important HTML Tags

  • <h1> to <h6> — Headings ranging from the largest (h1) to the smallest (h6)
  • <p> — Defines a paragraph of text
  • <a href=""> — Creates a hyperlink to another page or website
  • <img src="" alt=""> — Embeds an image into the page
  • <ul> and <ol> — Unordered (bullet) and ordered (numbered) lists
  • <li> — Defines each individual list item
  • <div> — A generic container used to group and organize sections
  • <nav> — Defines the navigation section of a page
  • <header> — Defines the top header section of a page
  • <footer> — Defines the bottom footer section of a page

HTML, CSS and JavaScript Together

Modern websites are built using three core technologies that each play a distinct role:

HTML provides the structure and content — the skeleton of the page including all text, headings, images, and links.

CSS (Cascading Style Sheets) provides the design and appearance — colors, fonts, spacing, layouts, and visual styling.

JavaScript provides the behavior and interactivity — animations, form validation, dynamic content updates, and user interactions.
